# PC 4p 셋업 커버링 북

퍼펙트 클리어(PC) **4p 셋업**을 완전탐색 봇의 V\*로 평가한 전집.
회차(7-bag 위상)별 구성마다, **어떤 큐가 오더라도 그 큐의 최선 셋업을 쓸 수 있는** 최소 커버링 집합을 싣습니다.

**→ https://muse918.github.io/pc-setup-book/**

| | |
|---|---|
| 전체 평균 PC 확률 | **98.11%** (7개 bag 페이즈 균등) |
| 전체 평균 V\* | 4,267 |
| 수록 | 8회차 · 568구성 · 7,018셋업 |

- **V\*** = 앞으로 연속으로 낼 수 있는 PC 개수의 기대값 (이론 최대 ≈ 4353.6, dead는 0으로 포함)
- **PC%** = 이번 PC가 풀릴 확률. 셋업 카드의 값은 (필드, 남은 미노)로 정해지는 값이라 일반 PC 솔버와 일치하고,
  평균 PC 확률은 그 셋업을 실제로 쓰는 큐들의 남은 리빌 순열을 전수 열거해 냅니다.

회차별 평균 PC 확률: 7회차 99.83% · 2회차 99.01% · 5회차 98.86% · 3회차 97.77% · 4회차 97.77% · 6회차 96.93% · 1회차(중복 포함) 96.61%

1회차 페이지에는 두 가지 보기 옵션이 있습니다.
**8회차 통합**은 중복 구성(X&gt;Y)을 1회차 탭에 함께 놓고, **X&gt;X 분해**는 `full`을 선두(홀드) 미노별 7개 구성으로 나눕니다.

## 계산

15.2M 필드 × 817,740 큐상태 MDP의 정확 V\*(f64 policy iteration)를 기반으로,
셋업 가격은 (필드, 남은 미노 multiset)별 확률가중 클래스 평균, 표시 V\*와 PC 확률은 그 셋업을 쓰는 큐들의 조건부 기대값입니다.
빌드 가능성은 실제 movegen(SRS + Jstris 180)으로 검증했고, 큐 가중치는 hold 이력이 실제로 가능한 순서 배치 수로 셉니다.
